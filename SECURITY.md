# Security policy

## Reporting a vulnerability

Please **do not** report security problems in public issues.

Report them privately through GitHub: go to the repository's **Security** tab and click **[Report a vulnerability](https://github.com/renangomide/morph/security/advisories/new)**. Include what you found, how to reproduce it (a sample file if one is needed), and the Morph version (Settings ▸ About).

You will get an answer as soon as possible. Once a fix is released, the advisory is published with credit to you, unless you prefer otherwise.

## Supported versions

Only the latest release gets security fixes.

## Scope

Examples of what counts: a crafted file that makes Morph run code, write outside the output folder, or modify or delete the original files; anything that crashes or hangs File Explorer through the right-click menu; problems in the installer scripts (`Install.cmd`, `Uninstall.cmd`).
